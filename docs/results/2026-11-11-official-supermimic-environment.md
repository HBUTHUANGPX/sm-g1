## Reset / recovery / termination
- Local normal RSI perturbs reference xyz ±(.05,.05,.01); rotation via SO(3) exponential with vector components ±(.1,.1,.2); linear velocity ±(.5,.5,.2); angular velocity ±(.52,.52,.78); joints ±.1, then clips joint positions (L envs/mdp/commands.py:25-31,186-234,254-256). Ordinary training resets additionally lift root .20m (same:281-284,416). Official inherited reset exact values unverified.
- Local recovery is selected with .15 probability, yaw from reference, independent roll/pitch U(-pi,pi), reference joints ±.2; all velocities zero; collision-corner placement ensures lowest corner .15m above floor (L envs/mdp/commands.py:235-253,263-279; core/recovery.py:11-19,156-170). This is an intentional recovery extension; not visible in official overlay, but absence from unavailable base cannot be asserted absolutely.
- Local recovery enables four raw threshold groups height .20m, tilt .8, max ankle and max wrist aligned position error .20m (L envs/configs/base.py:165-179; envs/manager_based.py:62-67; envs/mdp/terminations.py:6-22; core/recovery.py:109-128). Endpoints use torso/waist yaw alignment plus reference anchor height, not raw world endpoint displacement.
- Real recovery training samples independent per-group termination draws after threshold violation: root p=.02/3≈.006667 each; ankle/wrist p=.02/.5=.04 each. Only recovery-role rows get 4 seconds/200 source-state steps protection. This probabilistic acceptance also applies to non-recovery reset rows (without initial protection), not just the 15% recovery starts. Eval accepts all raw threshold failures immediately (L envs/managers.py:36-64; core/recovery.py:11-33,71-77).
- Local imagined hazard is gate*(1-product(1-p_i*sigmoid((err_i-thr_i)/width_i))), widths .02m,.04 tilt,.02m,.02m; source-state clock, four groups and OR survival (L core/recovery.py:80-89). Official imagined hazard is sigmoid((max(height/height_threshold, tilt/tilt_threshold)-1)/termination_softness), default softness .05; no protection clock or endpoint groups in this function (O envs/world_model_env.py:69-76,200-219; runners/supermimic_runner.py:59). Official overlay explicitly removes ee_body_pos real termination (O tasks/env_cfgs.py:198). This is confirmed major algorithm divergence. For an always-bad root criterion alone local expected wait is 3s after protection, whereas hard real failure in the unavailable base cannot be proven; official WM hazard tends to 1 at large normalized error, local four-group hazard is capped near 1-(1-.006667)^2*(1-.04)^2≈.09065/step. Different survival/gradient objective, intentional recovery behavior rather than evidence of replication.
- Reference timing differs visibly: official WM scores next state against cached current reference then advances frame (O envs/world_model_env.py:173-197,231-239); local termination compares physical post-state to next_reference_batch and protection uses episode_length-1 (L envs/mdp/terminations.py:6-14; envs/managers.py:50-62). This needs reconciliation against motion indexing/transition conventions before declaring an off-by-one defect; surface-level mismatch alone is insufficient.

## Priority conclusions
1. Do not label local recovered G1 training an equivalent official reproduction: actor information/history and termination survival law demonstrably differ.
2. Highest unresolved environmental parity risks are inherited official PD/action/delay/reset values and exact DR semantics. Missing dependency is an evidence gap, not proof local values are wrong.
3. Recovery and no-TN are user-authorized adaptations; assess their internal correctness separately from fidelity.
4. No simulation/hardware/throughput or training-outcome claims follow from this static audit.

Additional confirmed goal timing/scaling divergence: official frame offsets are [0,5,...,45] (~0..0.9s at 50Hz), O representations.py:173-189, and joint velocity goals are unscaled (192-200). Local reference frame offsets are [1,2,...,10] (~.02..0.20s), L data/reference.py:145-157, with qdot multiplied by .1 (79-80). These are substantively different anticipation horizons, even though both expose ten goal frames. The local relative orientation term is actually enabled by cfg in L envs/manager_based.py:143-147.
